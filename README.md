# naiveBayesClassifier | Detecção de Spam

Esse repositório possui um .ipynb de exemplo de implementação do Naive Bayes em Python usando scikit-learn para o dataset _Spam Data Dataset_, cuja publicação original pode ser encontrada [aqui](https://www.kaggle.com/datasets/abdallahwagih/spam-emails).

## instalando dependências:
Instale as dependências necessárias através do seguinte comando, se necessário:
```
pip install -r requirements.txt
```

## estrutura do repositório:
```
.
├── data
│   └── spam.csv
├── LICENSE
├── notebooks
│   └── naive-bayes.ipynb
├── README.md
└── requirements.txt
```
---
- ``/data``: armazena o dataset em .csv;
- ``/notebooks``: armazenda o arquivo .pynb com os experimentos.
